# Cyber History Map

[Explore Cyber History Map](https://cyberhistorymap.com/)

Cyber History Map is an interactive guide to cybersecurity history. It brings together incidents, people, organizations, and technical milestones so you can follow how they connect across decades.

- **Map** — Follow connections between records.
- **Timeline** — Browse events in chronological order.
- **Catalogue** — Look up a specific record.

## Sources and dates

Start with the sources linked from a record when checking a claim. The date of an event and the date a source was published can differ. If an exact date is unclear, include the best supported date range and explain what the source establishes.

## Contribute

This is the public feedback repository for Cyber History Map. If you find an error, a missing event, or a connection worth documenting, [open a GitHub issue](https://github.com/tonycgh/cyber-history-map-public/issues/new/choose). Include a link to the relevant record if one exists and a public source that supports your suggestion. If you suggest a connection, name both records and explain how they relate.

Please use public sources and keep personal or confidential information out of issues.
